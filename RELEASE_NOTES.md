## Фикс мобильного интернета — DNS без зависимости от тоннеля

**Причина проблемы на 4G/5G:** DNS для зарубежных сайтов шёл через VPN-тоннель (hysteria2). Если тоннель ещё не успел поднять соединение — DNS зависал, и весь интернет вставал. Это не зависело от того, включён cap или нет.

**Что изменили:**
- `remote` DNS теперь идёт напрямую (DoH → 8.8.8.8), без proxy. Тоннель больше не нужен для разрешения DNS.
- Маршрутизация трафика не изменилась: зарубежные сайты всё равно идут через прокси по IP-правилам. DNS просто больше не блокирует старт.
- Вернули bandwidth cap 10 Mbps на 4G/5G (без него операторский QUIC-сессию дропает при первом BBR-всплеске).

Если мобильный интернет по-прежнему не работает — нажмите LOG и пришлите лог.
